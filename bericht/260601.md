## Vorbereitungen (MacOS)

`setup.sh` im gleichen Ordner erstellen. 

```shell
#!/bin/bash
set -e

docker build -t pwn-env .

docker rm -f pwn 2>/dev/null || true

docker run -it --rm --name pwn -v "$(pwd):/code" -w /code pwn-env bash
```

Diese Shell erstellt einen Docker container

`debug.sh` auch im gleichen ordner. Wird dann im Docker-Container ausgeführt.

```shell
#!/bin/bash
set -e

chmod +x pwcheck

patchelf --set-interpreter /usr/lib/x86_64-linux-gnu/ld-linux-x86-64.so.2 \
         --set-rpath /usr/lib/x86_64-linux-gnu pwcheck

qemu-x86_64 -g 1234 ./pwcheck &
QEMU_PID=$!

sleep 1

gdb-multiarch -q -x .gdbinit /code/pwcheck

kill "$QEMU_PID" 2>/dev/null || true
```

Dieses file patched die libary, damit gdb durch qemu-x86_64 ausführbar ist.

### Anmerkung

Durch die beiden scripts ist jetzt gdb verwendbar, aber man kann durch set keine Werte verändern :(

Deshalb sind die Ausschnitte, in denen set verwendet werden von [Matthias](187matthias.github.io/4AHITS_ITSE_Chen/berichte/Opcode%20Patching%20am%2015.06.2026.html)

1. `b main` erstellt einen breakpoint nach dem Funktionsaufruf des mains. 
2. `run` bis zum breakpoint ausführen
3. `disas` gibt den code in Assembly aus



Um die Passwortabfrage jetzt zu überspringen werden muss der jump Befehl übersprungen werden.

#### Jump-Adresse (ausschnitt gdb):

```assembly
   0x00005555555571a5 <+69>:	je     0x55555555723d <main()+221>
```

#### `je` → `nop`

```assembly
(gdb) set {unsigned char}0x00005555555551a5 = 0x90
(gdb) set {unsigned char}0x00005555555551a6 = 0x90
(gdb) set {unsigned char}0x00005555555551a7 = 0x90
(gdb) set {unsigned char}0x00005555555551a8 = 0x90
(gdb) set {unsigned char}0x00005555555551a9 = 0x90
(gdb) set {unsigned char}0x00005555555551aa = 0x90
```



### Übung (pwn add to sub)

#### Zeile, in der addiert wird:

```assembly
	0x0000555555555224 <+196>:   add    -0xc(%rbp),%eax
```

Um dies jetzt zu `sub` zu ändern muss man den Wert der Adresse, in der `add` drinnen steht auf `0x2b` (`sub`) ändern. Da man ja davor nochmals die Passworteingabe umgehen muss, werden die ersten sechs Zeilen erneut verwendet.

```assembly
(gdb) set {unsigned char}0x00005555555551a5 = 0x90
(gdb) set {unsigned char}0x00005555555551a6 = 0x90
(gdb) set {unsigned char}0x00005555555551a7 = 0x90
(gdb) set {unsigned char}0x00005555555551a8 = 0x90
(gdb) set {unsigned char}0x00005555555551a9 = 0x90
(gdb) set {unsigned char}0x00005555555551aa = 0x90

(gdb) set {unsigned char}0x0000555555555224 = 0x2b
```
