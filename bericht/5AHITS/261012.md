### Übung  2.2 (PHP Aufgaben)

#### Notenverwaltung

```php
<form method="post">

    Noten (mit Komma getrennt): <input type="text" name="noten">
<button>Berechnen</button>
</form>
<?php

if (isset($_POST['noten'])) {

    $noten = explode(",", $_POST['noten']);
 
    $positiv = 0;

    foreach ($noten as $note) {

        if ($note <= 4) {

            $positiv++;

        }

    }
 
    $durchschnitt = array_sum($noten) / count($noten);

    $beste = min($noten);

    $schlechteste = max($noten);

?>
<table border="1">
<tr><td>Noten</td><td><?php echo implode(", ", $noten); ?></td></tr>
<tr><td>Durchschnitt</td><td><?php echo round($durchschnitt, 2); ?></td></tr>
<tr><td>Beste Note</td><td><?php echo $beste; ?></td></tr>
<tr><td>Schlechteste Note</td><td><?php echo $schlechteste; ?></td></tr>
<tr><td>Positive Noten</td><td><?php echo $positiv; ?></td></tr>
</table>
<?php } ?>
 
```

> Ich habe es mit den Noten 1, 3, 5, 2 getestet: Durchschnitt 2.75, beste Note 1, schlechteste 5, positiv 3.
>
> 1. Formular: Ein Eingabefeld, in das mehrere Noten mit Komma getrennt eingegeben werden, zum Beispiel 1,3,5,2.
> 2. 1. If-Abfrage: Prüft, ob das Formular abgeschickt wurde.
> 3. explode(): Teilt die Eingabe beim Komma auf und speichert die Noten in einem Array.
> 4. foreach-Schleife: Geht jede Note durch. Eine If-Abfrage prüft, ob die Note 4 oder besser ist, und zählt dann die positiven Noten um 1 hoch.
> 5. Berechnungen: array_sum() geteilt durch count() ergibt den Durchschnitt. min() liefert die beste Note, max() die schlechteste.
> 6. Tabelle: Gibt alle Noten und die Ergebnisse in einer HTML-Tabelle aus. round() rundet den Durchschnitt auf 2 Kommastellen.

#### Zahlenratenspiel 

```php
<?php

session_start();
 
if (!isset($_SESSION['zahl'])) {

    $_SESSION['zahl'] = rand(1, 100);

    $_SESSION['versuche'] = 0;

}
 
$meldung = "";
 
if (isset($_POST['tipp'])) {

    $tipp = (int) $_POST['tipp'];

    $_SESSION['versuche']++;
 
    if ($tipp > $_SESSION['zahl']) {

        $meldung = "zu hoch";

    } elseif ($tipp < $_SESSION['zahl']) {

        $meldung = "zu niedrig";

    } else {

        $meldung = "richtig nach " . $_SESSION['versuche'] . " Versuchen";

        unset($_SESSION['zahl']);

    }

}

?>
<form method="post">
<input type="number" name="tipp">
<button>Raten</button>
</form>
<p><?php echo $meldung; ?></p>
<p>Versuche: <?php echo $_SESSION['versuche']; ?></p>
 
```

> 1. session_start(): Startet Session, damit Zahl und Versuche zwischen den Tipps gespeichert bleiben.
> 2. If-Abfrage: Gibt es noch keine Zahl, wird mit rand(1, 100) eine Zufallszahl erzeugt und die Versuche auf 0 gesetzt.
> 3. If-Abfrage: Wurde ein Tipp abgeschickt, wird er in eine Zahl umgewandelt und der Versuchszähler um 1 erhöht.
> 4. If / elseif / else: Vergleicht den Tipp mit der Zufallszahl. Ist er größer, kommt "zu hoch". Ist er kleiner, kommt "zu niedrig". Ist er gleich, kommt "richtig" und die Zahl wird gelöscht, damit ein neues Spiel startet.
> 5. Formular: Eingabefeld und Button schicken den Tipp per POST.
> 6. Ausgabe: echo zeigt die Meldung und die Anzahl der Versuche an.
